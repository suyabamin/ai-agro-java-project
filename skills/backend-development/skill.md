# Skill: Java and Spring Boot Backend

## Trigger
Use for Spring Boot APIs, domain logic, security, persistence, and Java OOP.

## Workflow
1. Read architecture, API, authorization, and coding standards.
2. Inspect Maven configuration and existing packages.
3. Keep controllers focused on HTTP concerns.
4. Put business rules in services/domain components.
5. Use DTOs and Bean Validation for API boundaries.
6. Derive identity from verified Firebase tokens.
7. Enforce farm/field/resource authorization on every protected operation.
8. Use repository abstractions for Firestore access.
9. Handle errors consistently without leaking internals.
10. Add unit and integration tests.
11. Run Maven tests/build and report results.

## OOP
Use encapsulation, abstraction, inheritance, polymorphism, composition, and association where they naturally improve the model. Avoid artificial inheritance solely to satisfy a checklist.
