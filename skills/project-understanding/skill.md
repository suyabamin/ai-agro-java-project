# Skill: Project Understanding

## Trigger
Use before starting a new task, milestone, or unfamiliar module.

## Procedure
1. Read `AGENTS.md`, `RULES.md`, `PRD.md`, `docs/architecture/ARCHITECTURE.md`, `TASKS.md`, and `MEMORY.md`.
2. Read relevant detailed docs.
3. Inspect repository status, directory tree, manifests, and existing implementation.
4. Identify the requested task and acceptance criteria.
5. Separate known facts, assumptions, and unknowns.
6. Report risks, dependencies, and files likely to change.
7. Propose a phased plan and approval gate.
8. Do not implement until scope is clear.

## Output
Provide concise project understanding, audit findings, plan, risks, and the exact approval needed.
