# Development Guide

## Repository applications
- `frontend/`: React web client.
- `backend/`: Spring Boot API and business logic.
- `ai-service/`: FastAPI inference service.
- `docs/`: project documentation.
- `skills/`: specialized agent workflows.
- `tasks/`: milestone-specific task details.

## General workflow
1. Read requirements and rules.
2. Audit current implementation.
3. Plan changes.
4. Implement one approved phase.
5. Test affected modules.
6. Run builds.
7. Update docs and memory.
8. Submit an evidence-based report.

## Local development
Each service should be runnable independently. Exact commands must be documented after scaffolding and dependency versions are selected.
