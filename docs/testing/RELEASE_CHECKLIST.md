# Release Checklist

## Scope
- [ ] Release scope approved.
- [ ] Requirements and known limitations documented.
- [ ] No unapproved feature changes.

## Quality
- [ ] Automated tests executed.
- [ ] Builds successful.
- [ ] Critical user flows tested.
- [ ] Authorization tests passed.
- [ ] Responsive and accessibility checks performed.
- [ ] Dependency/security review completed.

## Security and operations
- [ ] No secrets in repository/artifacts.
- [ ] Production environment variables configured securely.
- [ ] Firestore rules and backend authorization reviewed.
- [ ] Logs avoid sensitive data.
- [ ] Backup/recovery approach documented.
- [ ] Monitoring and rollback plan prepared.

## AI
- [ ] Model version recorded.
- [ ] Evaluation evidence available.
- [ ] Limitations displayed.
- [ ] Demo outputs clearly labelled.

## Approval
- [ ] Owner approval received.
- [ ] Deployment/publishing explicitly authorized.
