# Design System

## Principles
Consistency, readability, accessibility, responsive behavior, and reusable components.

## Foundations
Define design tokens for:
- Color
- Typography
- Spacing
- Radius
- Elevation
- Breakpoints
- Motion
- Z-index

## Components
Buttons, text fields, selects, dialogs, cards, tables, tabs, badges, alerts, breadcrumbs, navigation, pagination, charts, upload controls, and status indicators.

## States
Every interactive component should define default, hover, focus, active, disabled, loading, and error states where relevant.

## Implementation
Centralize tokens and shared components. Avoid one-off styling that creates inconsistent patterns. Do not claim conformance to a design system until implemented and reviewed.
