# Color and Typography

## Proposed palette direction
These are starting tokens, subject to visual review:
- Primary: agricultural deep green
- Secondary: muted leaf green
- Accent: warm amber for highlights
- Background: warm off-white
- Surface: white
- Text: dark charcoal
- Muted text: neutral gray
- Error: accessible red
- Warning: amber
- Success: green

## Typography
Use a highly readable sans-serif family with clear hierarchy. Use consistent sizes and line heights for page titles, section headings, body text, labels, and helper text.

## Rules
- Check text/background contrast.
- Do not communicate status using color alone.
- Keep body text comfortable on mobile.
- Use tabular numerals for measurements and financial values where useful.
- Final exact color values and font choices should be approved in the design implementation phase.
