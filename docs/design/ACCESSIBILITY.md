# Accessibility Guidelines

- Use semantic HTML landmarks and headings.
- All controls must be keyboard accessible.
- Provide visible focus indicators.
- Associate labels and instructions with form fields.
- Provide text alternatives for meaningful images.
- Do not rely on color alone.
- Maintain adequate contrast.
- Announce important asynchronous status changes accessibly.
- Support reduced-motion preferences.
- Ensure dialogs manage focus correctly.
- Test with keyboard navigation and, where possible, screen readers.
