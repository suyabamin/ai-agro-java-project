# Responsive Design

## Targets
Support narrow mobile screens, tablets, laptops, and wide desktop layouts.

## Guidelines
- Use mobile-first layout constraints.
- Avoid fixed widths that cause horizontal overflow.
- Convert dense tables to responsive layouts or controlled horizontal scrolling.
- Keep primary actions reachable.
- Use touch targets suitable for mobile.
- Make navigation collapse predictably.
- Test forms, dialogs, charts, upload controls, and dashboards at multiple widths.

## Verification
Record actual viewport sizes and browser/device test results. Do not claim responsive support based only on CSS inspection.
