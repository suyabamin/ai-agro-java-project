# Contributing to AgroAI

## Before contributing
- Read `AGENTS.md` and `RULES.md`.
- Read the relevant product, architecture, and design documents.
- Check `TASKS.md` for approved scope.
- Inspect existing code before changing it.

## Development process
1. Describe the issue or task.
2. Identify affected services and files.
3. Create an implementation plan.
4. Implement a focused change.
5. Add/update tests.
6. Run tests and builds.
7. Update documentation and changelog.
8. Request review.

## Code quality
- Follow language-specific conventions.
- Avoid committing secrets or generated build artifacts.
- Keep changes focused and explain non-obvious decisions.
- Do not claim checks passed unless they were executed.

## Git
Use branches and commits only when the repository owner authorizes the workflow. Do not push or publish without approval.
